# ATOM Self-Balancing Robot

An ESP32-based self-balancing robot developed using
embedded systems, sensor integration, and PID control.

## Project Structure

- `firmware/` - ESP32 firmware
- `libraries.md` - Required Arduino libraries
- `tuning_page.html` - PID tuning interface
- `README.md` - Project documentation

## Hardware

- ESP32
- MPU6050
- L293D motor driver
- Two DC geared motors
- 7.4V lithium-ion battery
- LM2596 buck converter

## Firmware

The `self_balancing_robot.ino` file contains the
robot's Arduino firmware.
